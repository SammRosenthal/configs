# zed

`settings.json` is linked to `~/.config/zed/settings.json`.

Only the basics are set: font size 16 for both the UI and the editor, and the
theme follows the system (One Light / One Dark).

Zed's conversations, prompt library and themes stay in `~/.config/zed` and
aren't tracked.

## Handy

| Action                   | Keys / command                          |
| ------------------------ | --------------------------------------- |
| Command palette          | `Cmd+Shift+P`                           |
| Open these settings      | `Cmd+,`                                 |
| See every default setting | palette: `zed: open default settings` |
| Enable vim mode          | add `"vim_mode": true` to `settings.json` |
